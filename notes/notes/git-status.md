# Understanding Git States

Git tracks files through different states.

## 1. Working Directory
This is where we create or edit files.

## 2. Staging Area
The staging area contains changes prepared for the next commit.

## 3. Repository
The repository stores committed versions of files.

## Useful Commands

- `git status` — Check the current state of files.
- `git add .` — Stage changes.
- `git commit -m "message"` — Save changes in a commit.
- `git log --oneline` — Display a short history of commits.

These commands help us manage and track changes in a project.
