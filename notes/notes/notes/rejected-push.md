# Understanding a Rejected Git Push

## What is a rejected push?
A rejected push happens when GitHub refuses to accept changes from a local repository.

## Common reasons
- The remote repository contains changes that are missing locally.
- The local branch is behind the remote branch.
- The push does not meet repository rules.

## How to fix it
1. Read the error message carefully.
2. Fetch the latest changes.
3. Integrate the remote changes when appropriate.
4. Resolve any conflicts.
5. Push again.

## Important
Always understand why a push was rejected before trying again. Avoid force-pushing because it may overwrite other people's work.
